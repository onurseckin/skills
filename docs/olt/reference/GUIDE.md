> **Authoritative Charter**: All reference manuals in this directory must strictly comply with the master [OLT Documentation Engineering Charter](../GUIDELINES.md).

## Key Reference Requirements:

1. **Target Audience**: Skill consumers, system operators, and AI agents.
2. **Concise & Operational**: Keep reference guides compact, copy-pasteable, and practical.
3. **Deep Theory in Architecture**: Exhaustive CLI catalogs, error codes, state schemas, and verification engines reside in [Architecture Chapters 14–17](../architecture/index.md).
4. **Interactive Navigation**: Maintain 4-way header and footer navigation meshes.
