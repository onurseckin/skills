> **Authoritative Charter**: All architecture documents in this directory must strictly comply with the master [OLT Documentation Engineering Charter](../GUIDELINES.md).

## Key Architecture Requirements:

1. **Target Length**: 250–800 lines per document.
2. **Visuals**: Every section must include at least one ASCII system diagram and/or Mermaid state chart.
3. **Rigorous Theory**: Include LaTeX math for concurrency, hashing, APCA contrast, and graph algorithms.
4. **No Raw Code Dumps**: Focus on system architecture, interface contracts, and conceptual models.
5. **Interactive Navigation**: Maintain 4-way header and footer navigation meshes.
