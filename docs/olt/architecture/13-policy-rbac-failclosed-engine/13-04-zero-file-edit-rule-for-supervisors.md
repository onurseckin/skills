## 1. Structural Rationale for Delegation Enforcement

Supervisory agents (Tier 0 Mind, Tier 1 Orchestrator, Tier 2 Coordinator) exist to manage roadmaps, graph compilation, wave synchronization, and lease oversight.

If a supervisor attempts to write code directly:

1. It depletes its cognitive token window on low-level implementation details.
2. It loses high-level graph oversight of other parallel tasks.
3. It bypasses the independent validation and evidence gates designed to evaluate implementers.

**The Invariant ($C_8$)**: Any supervisory role attempting direct file edits is immediately aborted. All code mutations MUST be delegated to Tier 3 Implementers.
